# 运行、数据与排错

## 哪些文件只能留在本机

`config.local.json` 保存输出目录和学期日期；`pipeline_settings.json` 保存资源及课程规则。`.browser_profile/` 含登录状态，`.pipeline/` 含凭据、进度和日志。`catalog_playurls.json`、`weekly.json`、`ppt_清单.json` 可能含课程地址。这些文件默认均被 Git 忽略，整个输出目录也不会进入仓库。

账号功能是可选的。加密凭据只能由当前 Windows 用户解密；它不是可以公开分享的文件。浏览器登录状态也应当视作凭据。

## 完成判定

字幕提交采用 TXT/SRT 配对、最终 `done.json`、内容哈希和提交日志。未完成的 `.tmp` 不会凭大小或时长被当成完成。被外部修改的字幕保留并标记待核对，不自动重录覆盖。

图文讲义检查原图清单、OCR 覆盖、图片引用、原时间顺序、PDF 页数和最新字幕版本。保留手工讲义，在独立文件中合并新字幕。字幕噪音只记录候选，默认不删除；`clean_halluc.py --apply` 是使用者需要主动选择的操作。

## 资源与恢复

每课一个识别进程，结束后归还 GPU 和进程内存。CPU 内存映射模型权重，直接构造 FP16，避免完整 FP32 模型与权重同时挤占显存。OCR 子进程周期回收，PDF 每次只解码一张原图。

默认贪心解码，每块最多 15 分钟，超时限额为 `min(1800, max(60, 音频秒数×8))`。超时后进程退出、保留之前的块，仅贪心重试问题块一次；再次超时会明确标记待处理，不无限运行。

GPU 开始前等待温度低于 72°C，85°C 持续 20 秒暂停；可用内存不足 5GB、进程组超过 16GB、磁盘不足 10GB、断电时同样暂停。这些阈值是工作策略，可按设备保守配置。

`weekly_supervisor.py` 仅在配置窗口内恢复；独立恢复任务每 15 分钟检查。完成返回 0，未完成/资源暂停返回 40，窗口外或停止返回 30。不要把任务被触发视为所有课程已完成。

## 常见问题

| 现象 | 处理 |
|---|---|
| 登录预检需要验证 | 运行 `manage.py login`，在浏览器完成验证码或二次认证 |
| 登录可以但回放失败 | 保留日志中的错误类型；主流程会有界重试并刷新地址，不需要编辑课程 URL |
| 提示显存不足 | 等其他 GPU 工作结束，程序会在窗口内恢复；不会关闭其他软件 |
| PPT 探测失败 | 不能直接当成无 PPT；先检查登录、网络和浏览器是否被占用 |
| 字幕存在外部修改 | 保留原件，查看 `transcript/done.json` 与人工修订；不要删除标记来强制覆盖 |
| 课程名字或周次不对 | 检查初始化的学期起始日期。更换学期请使用独立项目/数据目录 |
| 到 08:00 还没做完 | 保存已有音频、OCR、字幕块，下一允许窗口接续 |

源码中的平台地址和字段来自目前的同济课程回放接口。平台界面、课程类型和账号权限可能不同；请在 Issue 中提供脱敏的错误和复现步骤。不要贴真实课程地址来复现。
